## 📂 Estructura del Entrenamiento

Hemos dividido el gimnasio en dos grandes zonas para trabajar distintos grupos musculares:

### 1. Calistenia de Código (Ejercicios de Lógica)
Ejercicios fundamentales para entrar en calor. Aquí encontrarás retos de lógica pura, manipulación de strings y matemáticas básicas. Ideal para principiantes o para precalentar antes de una entrevista.

### 2. Levantamiento de Peso (Algoritmos y Estructuras de Datos)
Aquí están las mancuernas pesadas. En esta sección nos enfocamos en complejidad algorítmica, árboles, grafos y optimización. ¡Solo para valientes!
