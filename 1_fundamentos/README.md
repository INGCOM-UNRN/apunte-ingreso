# Diagramas SVG - Capítulo 1: Fundamentos

Este directorio contiene todos los diagramas SVG utilizados en el Capítulo 1 del apunte de Fundamentos de Programación en Python.

## Contenido

### Diagramas conceptuales

1. **variable_caja.svg** - Representación visual de las variables como "cajas" etiquetadas
2. **tipos_datos.svg** - Los 4 tipos de datos básicos en Python (int, float, str, bool)
3. **flujo_programa.svg** - Flujo de ejecución de un programa simple (Entrada → Procesamiento → Salida)

### Operadores

4. **operadores_aritmeticos.svg** - Los 7 operadores aritméticos con ejemplos
5. **operadores_comparacion.svg** - Los 6 operadores de comparación con tablas de verdad
6. **operadores_logicos.svg** - Los 3 operadores lógicos (and, or, not) con tablas completas
7. **precedencia_operadores.svg** - Orden de precedencia (PEMDAS) con ejemplos

### Conversión

8. **conversion_tipos.svg** - Conversión entre tipos de datos (casting)

## Características

Todos los diagramas están:
- ✅ En formato SVG (escalable sin pérdida de calidad)
- ✅ Con colores consistentes y accesibles
- ✅ Diseñados para ser didácticos y fáciles de entender
- ✅ Optimizados para impresión y pantalla

## Paleta de colores

- **Azul** (#1976d2, #e3f2fd): Variables, conversión de tipos
- **Verde** (#388e3c, #e8f5e9): Comparación, flujos correctos
- **Naranja** (#f57c00, #fff3e0): Operadores lógicos, advertencias
- **Púrpura** (#7b1fa2, #f3e5f5): Operadores aritméticos
- **Rojo** (#c62828): Valores False, errores

## Uso

Estos diagramas se referencian en el archivo principal `1_fundamentos.md` mediante la sintaxis:

```markdown
![Descripción](./1_fundamentos/nombre_archivo.svg)
```
