# Diagramas SVG - Capítulo 2: Control de Flujo

Este directorio contiene todos los diagramas SVG utilizados en el Capítulo 2 del apunte sobre Control de Flujo en Python.

## Contenido

### Condicionales

1. **if_decision.svg** - Diagrama de flujo de la estructura `if` simple
2. **if_else_decision.svg** - Diagrama de flujo de `if-else` (dos caminos)
3. **if_elif_else.svg** - Diagrama de flujo de `if-elif-else` (múltiples caminos)

### Bucles

4. **while_loop.svg** - Diagrama de flujo del bucle `while` con ejemplo
5. **for_loop.svg** - Diagrama de flujo del bucle `for` con `range()` y listas

### Conceptos Fundamentales

6. **indentacion.svg** - Explicación visual de la indentación en Python

## Características

Todos los diagramas están:
- ✅ En formato SVG (escalable sin pérdida de calidad)
- ✅ Con código de ejemplo incluido
- ✅ Coloreados para diferenciar flujos (verde=True, rojo=False)
- ✅ Con anotaciones y explicaciones

## Paleta de Colores

### Estructuras de Control
- **Verde** (#c8e6c9, #2e7d32): Inicio/Fin, ramas True
- **Amarillo** (#fff9c4, #f57f17): Decisiones (rombos)
- **Azul** (#bbdefb, #1565c0): Procesos, acciones
- **Rojo** (#ffcdd2, #c62828): Ramas False, errores

### Bucles
- **Púrpura** (#e1bee7, #7b1fa2): Bucles `for`
- **Rojo punteado**: Flechas de retorno (loop)

## Uso

Estos diagramas se referencian en el archivo principal `2_control_flujo.md` mediante:

```markdown
![Descripción](./2_control_flujo/nombre_archivo.svg)
```

## Diagrama de Flujo Estándar

Los diagramas siguen la notación estándar:
- **Óvalo**: Inicio/Fin
- **Rombo**: Decisión (condición)
- **Rectángulo**: Proceso/Acción
- **Flechas**: Flujo de ejecución
