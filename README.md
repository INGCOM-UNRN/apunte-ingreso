# Apunte de Ingreso - Ingeniería en Computación

Apunte para el curso de ingreso a la carrera de Ingeniería en Computación. Este material introduce la programación desde cero utilizando Python como lenguaje de enseñanza.

El curso cubre exhaustivamente todos los conceptos fundamentales y avanzados de Python necesarios para comenzar la carrera de Ingeniería en Computación con bases sólidas y profesionales.

Ingresantes a la carrera sin experiencia previa en programación.

## ¿Necesitas ayuda?

¡No te quedes con dudas! Programar es un desafío y preguntar es una parte fundamental del proceso de aprendizaje. Aquí tenés varios canales para obtener ayuda:

- **En las Clases:** Aprovechá el espacio de consulta presencial o virtual para preguntar directamente a los docentes y ayudantes. ¡Están ahí para ayudarte! Prepara tus preguntas con anticipación para aprovechar el tiempo al máximo.

- **Canal de Discord:** Unite a nuestro servidor de Discord, donde podrás interactuar con tus compañeros, ayudantes y docentes. Es un excelente lugar para:
  - Plantear dudas sobre los ejercicios.
  - Compartir tu código (¡y tus errores!) para recibir feedback.
  - Colaborar con otros estudiantes.

- **Grupos de WhatsApp:** Los grupos de WhatsApp del curso de ingreso son ideales para preguntas rápidas y para mantenerte en contacto con tus compañeros. Recordá ser respetuoso y seguir las normas del grupo.

### ¿Cómo hacer una buena pregunta?

Para que podamos ayudarte mejor, intenta seguir estos pasos al preguntar:
1. **Describe el problema:** ¿Qué estás intentando hacer?
2. **Mostrá tu código:** Compartí el fragmento de código relevante.
3. **Explica el error:** ¿Qué sucede? ¿Hay algún mensaje de error? Copialo y pegalo.
4. **Contá lo que ya intentaste:** Explica qué soluciones probaste para que no te sugieran lo mismo.

¡Preguntar bien es una habilidad que te servirá durante toda tu carrera!
