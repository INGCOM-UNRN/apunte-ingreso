# Pseudocódigo

**Definición:**
* Escribir el algoritmo en "español estructurado"
* Parecido a código real pero legible
* Punto medio entre humano y máquina

**Ventaja:**
* No requiere sintaxis exacta
* Se enfoca en la lógica
* Fácil de traducir a cualquier lenguaje

---

<!-- _header: 'Palabras clave' -->

# Vocabulario del pseudocódigo

**Básicas:**
* `INICIO` / `FIN` - Marcan comienzo y final
* `LEER` - Pedir datos al usuario
* `MOSTRAR` - Mostrar datos al usuario
* `⟸` - Asignación (guardar un valor)

**Decisiones:**
* `SI ... ENTONCES` - Condicional
* `SINO` - Camino alternativo
* `FIN_SI` - Cierre de condicional

---

<!-- _header: 'Palabras clave' -->

# Vocabulario: Lazos

**Repeticiones:**
* `MIENTRAS ... HACER` - Repetir mientras condición
* `FIN_MIENTRAS` - Cierre del lazo
* `PARA ... DESDE ... HASTA` - Lazo con contador
* `FIN_PARA` - Cierre del lazo for

**Comentarios:**
* `#` - Comentario explicativo

---

<!-- _header: 'Estructura' -->

# Plantilla básica

```
INICIO NombreDelAlgoritmo
    # Acá van los pasos
FIN
```

**Siempre:**
* Comienza con INICIO
* Termina con FIN
* Los pasos van indentados (con espacios)

---

<!-- _header: 'Ejemplo 1' -->

# Sumar dos números

```
INICIO SumarDosNumeros
    # Pedir los números
    MOSTRAR "Ingrese el primer número:"
    LEER numero1
    
    MOSTRAR "Ingrese el segundo número:"
    LEER numero2
    
    # Hacer la suma
    suma ⟸ numero1 + numero2
    
    # Mostrar el resultado
    MOSTRAR "La suma es:", suma
FIN
```

---

<!-- _header: 'Ejemplo 2' -->

# Mayor de edad

```
INICIO MayorDeEdad
    # Pedir edad
    MOSTRAR "Ingrese su edad:"
    LEER edad
    
    # Verificar
    SI edad >= 18 ENTONCES
        MOSTRAR "Sos mayor de edad"
    SINO
        MOSTRAR "Sos menor de edad"
    FIN_SI
FIN
```

<!--
Notá la indentación dentro del bloque SI-SINO. Esto es importante para ver qué código se ejecuta en cada caso.
-->

---

<!-- _header: 'Detalles' -->

# Estructura SI-ENTONCES-SINO

**Observá:**
* El `SI` tiene un `ENTONCES` al final
* Lo que está dentro está indentado
* Hay un `SINO` para el caso contrario
* Cierra con `FIN_SI`

**Indentación:**
* Usa espacios para mostrar jerarquía
* Python usa esto en el código real

---

<!-- _header: 'Ejemplo 3' -->

# Contar del 1 al 5

```
INICIO ContarHastaCinco
    # Empezar desde 1
    contador ⟸ 1
    
    # Repetir mientras sea <= 5
    MIENTRAS contador <= 5 HACER
        MOSTRAR contador
        contador ⟸ contador + 1
    FIN_MIENTRAS
    
    MOSTRAR "¡Terminé de contar!"
FIN
```

---

<!-- _header: 'Detalles' -->

# Estructura MIENTRAS

**Observá:**
* `MIENTRAS ... HACER` es un lazo
* Todo lo indentado se repite
* `contador ⟸ contador + 1` es crucial
* Sin esto, lazo infinito
* Cierra con `FIN_MIENTRAS`

---

<!-- _header: 'Ejemplo 4' -->

# Promedio de 3 números

```
INICIO PromedioDeTres
    # Entrada
    MOSTRAR "Ingrese tres números:"
    LEER num1, num2, num3
    
    # Proceso
    suma ⟸ num1 + num2 + num3
    promedio ⟸ suma / 3
    
    # Salida
    MOSTRAR "El promedio es:", promedio
FIN
```

---

<!-- _header: 'Partes' -->

# Las tres partes

Todo algoritmo tiene:

**1. Entrada (📥):**
* LEER datos del usuario

**2. Proceso (⚙️):**
* Cálculos y operaciones

**3. Salida (📤):**
* MOSTRAR resultados

---

<!-- _header: 'Comparación' -->

# Pseudocódigo vs Python

**Pseudocódigo:**
```
INICIO Saludar
    MOSTRAR "Hola Mundo"
FIN
```

**Python:**
```python
def saludar():
    print("Hola Mundo")
```

**Similar pero no igual**

---

<!-- _header: 'Comparación' -->

# Estructuras equivalentes

| Pseudocódigo | Python |
|:-------------|:-------|
| `LEER x` | `x = input()` |
| `MOSTRAR x` | `print(x)` |
| `x ⟸ 5` | `x = 5` |
| `SI ... ENTONCES` | `if ...:` |
| `MIENTRAS ... HACER` | `while ...:` |

---

<!-- _header: 'Tips' -->

# Consejos para pseudocódigo

**Sé claro:**
* Escribe como si explicaras a alguien
* No uses abreviaturas raras

**Usa indentación:**
* Muestra qué está dentro de qué

**Comenta:**
* Explica secciones complejas
* Usa `#` para comentarios

# Ejercicio: Número par o impar

**Problema:**
* Leer un número
* Decir si es par o impar

**Pista:**
* Un número es par si `numero % 2 == 0`
* `%` es el operador módulo (resto)

**Estructura:**
* INICIO
* LEER numero
* SI ... usar condición de arriba
* MOSTRAR resultado
* FIN
