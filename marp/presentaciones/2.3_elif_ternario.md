<!-- _header: '¿Qué es elif?' -->

# Más de dos caminos

**Con if-else solo hay 2 opciones:**
* Si se cumple → opción A
* Si no → opción B

**¿Y si hay 3, 4, 5 opciones?**
* Ahí usás `elif`
* "else if" = "sino si"

---

<!-- _header: 'Sintaxis' -->

# Estructura if-elif-else

```python
if condicion1:
    # Primera opción
elif condicion2:
    # Segunda opción
elif condicion3:
    # Tercera opción
else:
    # Si ninguna se cumple
```

**Solo se ejecuta UNA**

---

<!-- _header: 'Analogía' -->

# Semáforo de 4 luces

```python
velocidad = 80

if velocidad > 120:
    print("🔴 ¡Peligro! Muy rápido")
elif velocidad > 80:
    print("🟡 Cuidado, reducí")
elif velocidad > 40:
    print("🟢 Velocidad normal")
else:
    print("🔵 Muy lento")
```

**Revisa en orden, se detiene en la primera True**

---

<!-- _header: 'Ejemplo' -->

# Sistema de calificaciones

```python
nota = 85

if nota >= 90:
    print("Excelente - A")
elif nota >= 70:
    print("Muy Bueno - B")  # Se ejecuta esta
elif nota >= 60:
    print("Bueno - C")
elif nota >= 40:
    print("Regular - D")
else:
    print("Insuficiente - F")
```

---

<!-- _header: 'Flujo de evaluación' -->

# ¿Cómo funciona con nota = 85?

**Evaluación paso a paso:**
1. ¿nota >= 90? → No (85 < 90) → Siguiente
2. ¿nota >= 70? → **¡Sí!** (85 >= 70) → ✅ Ejecuta
3. **Se detiene acá**
4. No evalúa nota >= 60
5. No evalúa nota >= 40
6. No ejecuta el else

**Solo ejecuta la primera que es True**

---

<!-- _class: inverse -->

# <!-- fit --> ¡Cuidado con el orden!
## Es fundamental

---

<!-- _header: 'Orden correcto' -->

# De más restrictivo a menos

**✅ Correcto:**
```python
if nota >= 90:    # Más específico
    print("A")
elif nota >= 80:
    print("B")    # Se ejecuta para 85
elif nota >= 70:
    print("C")
else:
    print("F")
```

**Orden:** Mayor → Menor

---

<!-- _header: 'Orden incorrecto' -->

# Problema con el orden invertido

**❌ Incorrecto:**
```python
if nota >= 70:    # Muy general
    print("C")    # ¡Atrapa 85!
elif nota >= 80:  # Nunca se alcanza
    print("B")
elif nota >= 90:  # Nunca se alcanza
    print("A")
```

**Problema:** Primera condición atrapa todo >= 70

---

<!-- _header: 'Regla de oro' -->

# Ordená correctamente

**Regla:**
* Más específico primero
* Menos específico después
* `else` al final (atrapa todo lo demás)

**Piensa:** "¿Esta condición incluye a la siguiente?"
* Si sí → están en orden incorrecto

---

<!-- _header: 'Comparación' -->

# Múltiples if vs if-elif-else

**Múltiples if separados:**
```python
edad = 25
if edad >= 18:
    print("Adulto")      # Se ejecuta
if edad >= 13:
    print("Adolescente") # También
if edad >= 0:
    print("Persona")     # También
```

**Resultado:** 3 mensajes

---

<!-- _header: 'Comparación' -->

# Con if-elif-else

```python
edad = 25
if edad >= 18:
    print("Adulto")      # Se ejecuta
elif edad >= 13:
    print("Adolescente") # No se evalúa
elif edad >= 0:
    print("Persona")     # No se evalúa
```

**Resultado:** 1 solo mensaje

**Solo la primera condición True**

<!-- _header: 'Operador ternario' -->

# Forma compacta para casos simples

**Sintaxis:**
```python
valor_si_true if condicion else valor_si_false
```

**Ejemplo:**
```python
edad = 20
estado = "Mayor" if edad >= 18 else "Menor"
print(estado)  # Mayor
```

**Una línea, solo para casos simples**

---

<!-- _header: 'Operador ternario' -->

# Cuándo usarlo

**✅ Bueno para:**
```python
# Asignar valor según condición
descuento = 0.2 if es_estudiante else 0

# Elegir mensaje
mensaje = "Aprobó" if nota >= 60 else "Reprobó"

# Máximo/mínimo
mayor = a if a > b else b
```

**❌ No para:**
* Condiciones complejas
* Múltiples acciones
* Código difícil de leer

---

<!-- _header: 'Comparación' -->

# Normal vs ternario

**Forma normal:**
```python
if edad >= 18:
    estado = "Mayor"
else:
    estado = "Menor"
```

**Forma ternaria:**
```python
estado = "Mayor" if edad >= 18 else "Menor"
```

**Mismo resultado, más compacto**

---

<!-- _header: 'Condicionales anidados' -->

# Un if dentro de otro

```python
edad = 20
tiene_licencia = True

if edad >= 18:
    if tiene_licencia:
        print("Puede conducir")
    else:
        print("Necesita licencia")
else:
    print("Muy joven para conducir")
```

**Indentación indica nivel**

---

<!-- _header: 'Condicionales anidados' -->

# Alternativa con and

**En vez de anidar:**
```python
if edad >= 18:
    if tiene_licencia:
        print("Puede conducir")
```

**Usa and:**
```python
if edad >= 18 and tiene_licencia:
    print("Puede conducir")
```

**Más simple y claro**

<!-- _header: 'Ejercicio' -->

# Calculadora de IMC

**Crea un programa que:**
1. Pida peso (kg) y altura (m)
2. Calcule IMC = peso / altura²
3. Clasifique:
   * < 18.5: Bajo peso
   * 18.5-24.9: Normal
   * 25-29.9: Sobrepeso
   * >= 30: Obesidad

---

<!-- _header: 'Ejercicio - Solución' -->

# Posible solución

```python
peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))

imc = peso / (altura ** 2)

if imc < 18.5:
    print("Bajo peso")
elif imc < 25:
    print("Peso normal")
elif imc < 30:
    print("Sobrepeso")
else:
    print("Obesidad")

print(f"Tu IMC: {imc:.1f}")
```

<!-- _header: 'Resumen' -->

# Para recordar

**elif:**
* Para más de 2 opciones
* Solo se ejecuta la primera True
* Orden importa: específico → general

**Operador ternario:**
* `valor1 if cond else valor2`
* Solo para casos simples

**Anidados:**
* if dentro de if
* Mejor usar and/or cuando sea posible

**Próximo:**
* Lazos while
