<!-- _header: '¿Qué es una lista?' -->

# Colección ordenada

**Lista:**
* Secuencia de elementos
* Cada uno en una posición
* Mantiene el orden
* Puede tener duplicados

**Como una fila de cajitas numeradas**

<!--
NOTAS DEL ORADOR:
- Analogía visual: Fila de casilleros de correo, o asientos numerados en el cine.
- "Ordenada" no significa "de menor a mayor", significa que si pongo "A" y luego "B", se quedan así.
- La diferencia con el Set es crucial: aquí importa EL LUGAR.
-->

---

<!-- _header: 'Características' -->

# Propiedades de las listas

**Ordenada:**
* Cada elemento tiene posición fija
* Posición = índice

**Mutable:**
* Podés cambiar elementos
* Agregar o quitar
* Modificar después de crear

**Versátil:**
* Cualquier tipo de dato
* Mezclados si querés

<!--
NOTAS DEL ORADOR:
- Mutabilidad: Puedo cambiar el contenido de la cajita 3 sin romper la caja.
- Heterogénea: `[1, "hola", True]` es válido en Python (aunque no siempre recomendable mezclar mucho).
-->

<!-- _header: 'Crear listas' -->

# Tres formas

**1. Lista vacía:**
```python
mi_lista = []
otra = list()
```

**2. Con elementos:**
```python
numeros = [1, 2, 3, 4, 5]
frutas = ["manzana", "banana", "naranja"]
```

**3. Mixta:**
```python
mixta = [1, "texto", 3.14, True]
```

<!--
NOTAS DEL ORADOR:
- `[]` es azúcar sintáctica para `list()`. Es lo más usado.

-->

<!-- _header: 'La regla del 0' -->

# Contamos desde 0

**¡IMPORTANTE!**
* Primer elemento → índice 0
* Segundo elemento → índice 1
* Tercer elemento → índice 2

```python
frutas = ["🍎", "🍌", "🍊"]
#        [0]   [1]   [2]

print(frutas[0])  # 🍎 Primera
print(frutas[1])  # 🍌 Segunda
print(frutas[2])  # 🍊 Tercera
```

<!--
NOTAS DEL ORADOR:
- ESTO ES CRÍTICO y suele confundir a principiantes
- Explicar por qué se cuenta desde 0 (herencia de C, eficiencia de memoria)
- Usar ejemplo físico: si hay 3 cajitas, se numeran 0, 1, 2
- Remarcar: posición 0 = primer elemento, NO el "cero-ésimo"
- Error común: intentar frutas[3] cuando solo hay 3 elementos (0,1,2)
- Hacer ejercicio mental: "Si tengo 5 elementos, ¿cuál es el último índice?" (4)

- "Off-by-one error" (Error por uno): Es el bug más común.
- Memorizar: El índice es la DISTANCIA desde el inicio. El primero está a distancia 0.
-->

---

<!-- _header: 'Índices negativos' -->

# Contar desde el final

**Con números negativos:**
* Último elemento → índice -1
* Penúltimo → índice -2

```python
frutas = ["🍎", "🍌", "🍊", "🍐"]

print(frutas[-1])  # 🍐 Última
print(frutas[-2])  # 🍊 Penúltima
print(frutas[-3])  # 🍌 Antepenúltima
```

**Útil cuando no sabés el tamaño**

<!--
NOTAS DEL ORADOR:
- Magia de Python. En otros lenguajes tendrías que hacer `lista[len(lista)-1]`.
- `-1` siempre es el último. Súper práctico.
-->

<!-- _header: 'Error común' -->

# Índice fuera de rango

**❌ Error:**
```python
frutas = ["🍎", "🍌"]

print(frutas[5])  # IndexError!
# Solo hay 2 elementos (índices 0 y 1)
```

**✅ Verificar tamaño:**
```python
print(len(frutas))  # 2
# Índices válidos: 0 a 1
```

<!--
NOTAS DEL ORADOR:
- `IndexError: list index out of range`.
- Si la longitud es N, el último índice válido es N-1.
-->

<!-- _header: 'Modificar elementos' -->

# Cambiar valores

**Asignar nuevo valor:**
```python
frutas = ["manzana", "banana", "naranja"]

frutas[1] = "pera"  # Cambiar segunda

print(frutas)
# ["manzana", "pera", "naranja"]
```

**Las listas son mutables**

<!--
NOTAS DEL ORADOR:
- Asignación por índice.
- Destruye el valor anterior en esa posición.
-->

---

<!-- _header: 'Agregar elementos' -->

# append() - Al final

```python
frutas = ["manzana", "banana"]

frutas.append("naranja")

print(frutas)
# ["manzana", "banana", "naranja"]
```

**append() agrega al final siempre**

<!--
NOTAS DEL ORADOR:
- El método más usado.
- Hace crecer la lista dinámicamente. No hace falta decir el tamaño antes.
-->

---

<!-- _header: 'Agregar elementos' -->

# insert() - En posición

```python
frutas = ["manzana", "banana"]

frutas.insert(1, "pera")  # posición, valor

print(frutas)
# ["manzana", "pera", "banana"]
```

**insert(índice, elemento)**

<!--
NOTAS DEL ORADOR:
- Desplaza todo lo demás a la derecha.
- Menos eficiente que `append` para listas muy grandes, pero útil.
-->

---

<!-- _header: 'Eliminar elementos' -->

# Tres formas

**remove() - Por valor:**
```python
frutas.remove("banana")  # Elimina "banana"
```

**pop() - Por índice:**
```python
fruta = frutas.pop(1)  # Elimina y retorna
```

**del - Por índice:**
```python
del frutas[0]  # Elimina primera
```

<!--
NOTAS DEL ORADOR:
- `remove` busca el primero que coincida y lo borra. Error si no está.
- `pop` saca el último por defecto (como una pila de platos).
- `del` es una instrucción de Python, no un método.
-->

# len(), in, +

**Longitud:**

**Pertenencia:**

<!-- _header: 'Recorrer listas' -->

# Lazo for

**Iterar elementos:**
```python
frutas = ["manzana", "banana", "naranja"]

for fruta in frutas:
    print(fruta)
```

**Salida:**
```
manzana
banana
naranja
```

<!--
NOTAS DEL ORADOR:
- La forma estándar de procesar listas.
- "Para cada fruta en frutas..."
-->

---

<!-- _header: 'Recorrer con índice' -->

# enumerate()

**Obtener índice y valor:**
```python
frutas = ["manzana", "banana", "naranja"]

for i, fruta in enumerate(frutas):
    print(f"{i}: {fruta}")
```

**Salida:**
```
0: manzana
1: banana
2: naranja
```

<!--
NOTAS DEL ORADOR:
- enumerate() es más elegante que usar range(len(lista))
- Explicar el unpacking: i, fruta = (índice, valor)
- Mostrar alternativa menos pythónica:
  for i in range(len(frutas)):
      print(f"{i}: {frutas[i]}")
- Mencionar parámetro start: enumerate(frutas, start=1) para índices desde 1
- Casos de uso: numerar elementos, necesitar posición y valor simultáneamente
- Ejercicio: crear lista numerada con prefijo de posición

- `enumerate` es pythónico. Evita hacer `range(len(lista))`.
- Desempaquetado de tupla `i, fruta`.
-->
