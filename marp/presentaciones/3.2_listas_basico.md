# Propiedades de las listas

**Ordenada:**
* Cada elemento tiene posición fija
* Posición = índice

**Mutable:**
* Podés cambiar elementos
* Agregar o quitar
* Modificar después de crear

**Versátil:**
* Cualquier tipo de dato
* Mezclados si querés

# Contamos desde 0

**¡IMPORTANTE!**
* Primer elemento → índice 0
* Segundo elemento → índice 1
* Tercer elemento → índice 2

```python
frutas = ["🍎", "🍌", "🍊"]
#        [0]   [1]   [2]

print(frutas[0])  # 🍎 Primera
print(frutas[1])  # 🍌 Segunda
print(frutas[2])  # 🍊 Tercera
```

<!--
NOTAS DEL ORADOR:

- Error común: intentar frutas[3] cuando solo hay 3 elementos (0,1,2)

<!-- _header: 'Índices negativos' -->

# Contar desde el final

**Con números negativos:**
* Último elemento → índice -1
* Penúltimo → índice -2

```python
frutas = ["🍎", "🍌", "🍊", "🍐"]

print(frutas[-1])  # 🍐 Última
print(frutas[-2])  # 🍊 Penúltima
print(frutas[-3])  # 🍌 Antepenúltima
```

**Útil cuando no sabés el tamaño**

<!-- _header: 'Error común' -->

# Índice fuera de rango

**❌ Error:**
```python
frutas = ["🍎", "🍌"]

print(frutas[5])  # IndexError!
# Solo hay 2 elementos (índices 0 y 1)
```

**✅ Verificar tamaño:**
```python
print(len(frutas))  # 2
# Índices válidos: 0 a 1
```

<!-- _header: 'Modificar elementos' -->

# Cambiar valores

**Asignar nuevo valor:**
```python
frutas = ["manzana", "banana", "naranja"]

frutas[1] = "pera"  # Cambiar segunda

print(frutas)
# ["manzana", "pera", "naranja"]
```

**Las listas son mutables**

---

<!-- _header: 'Agregar elementos' -->

# append() - Al final

```python
frutas = ["manzana", "banana"]

frutas.append("naranja")

print(frutas)
# ["manzana", "banana", "naranja"]
```

**append() agrega al final siempre**

---

<!-- _header: 'Agregar elementos' -->

# insert() - En posición

```python
frutas = ["manzana", "banana"]

frutas.insert(1, "pera")  # posición, valor

print(frutas)
# ["manzana", "pera", "banana"]
```

**insert(índice, elemento)**

<!-- _header: 'Eliminar elementos' -->

# Tres formas

**remove() - Por valor:**
```python
frutas.remove("banana")  # Elimina "banana"
```

**pop() - Por índice:**
```python
fruta = frutas.pop(1)  # Elimina y retorna
```

**del - Por índice:**
```python
del frutas[0]  # Elimina primera
```

# len(), in, +

**Longitud:**
```python
print(len(frutas))  # Cantidad
```

**Pertenencia:**
```python
print("manzana" in frutas)  # True/False
```

**Concatenar:**

<!-- _header: 'Recorrer listas' -->

# Lazo for

**Iterar elementos:**
```python
frutas = ["manzana", "banana", "naranja"]

for fruta in frutas:
    print(fruta)
```

**Salida:**
```
manzana
banana
naranja
```

---

<!-- _header: 'Recorrer con índice' -->

# enumerate()

**Obtener índice y valor:**
```python
frutas = ["manzana", "banana", "naranja"]

for i, fruta in enumerate(frutas):
    print(f"{i}: {fruta}")
```

**Salida:**
```
0: manzana
1: banana
2: naranja
```

# Lista de compras

**Crea un programa que:**
1. Cree lista vacía de compras
2. Agregue 3 productos
3. Muestre la lista
4. Elimine un producto
5. Muestre lista final

---

<!-- _header: 'Ejercicio - Solución' -->

# Posible solución

```python
# 1. Crear lista vacía
compras = []

# 2. Agregar productos
compras.append("pan")
compras.append("leche")
compras.append("huevos")

# 3. Mostrar
print("Lista inicial:", compras)

# 4. Eliminar
compras.remove("leche")

# 5. Mostrar final
print("Lista final:", compras)
```
