<!-- _header: '¿Qué hacen?' -->

# Comparar valores

**Operadores de comparación:**
* Comparan dos valores
* Responden Verdadero o Falso
* Siempre devuelven `bool`

**Es como preguntar:**
* "¿Soy más alto que Juan?"
* Respuesta: Sí (True) o No (False)

---

<!-- _header: 'Tipos de comparación' -->

# Los 6 operadores

**Igualdad:**
* `==` igual a
* `!=` diferente de

**Orden:**
* `>` mayor que
* `<` menor que
* `>=` mayor o igual que
* `<=` menor o igual que

---

<!-- _header: 'Igualdad' -->

# Igual y diferente

**Igual a (==):**
```python
5 == 5   # True
5 == 3   # False
```

**Diferente de (!=):**
```python
5 != 3   # True
5 != 5   # False
```

**Nota:** `==` no es `=` (asignación)

---

<!-- _header: 'Orden' -->

# Mayor y menor

**Mayor que (>):**
```python
8 > 5    # True
3 > 10   # False
```

**Menor que (<):**
```python
3 < 10   # True
8 < 5    # False
```

---

<!-- _header: 'Orden' -->

# Mayor/menor o igual

**Mayor o igual (>=):**
```python
5 >= 5   # True
5 >= 3   # True
3 >= 5   # False
```

**Menor o igual (<=):**
```python
3 <= 5   # True
5 <= 5   # True
8 <= 5   # False
```

---

<!-- _header: 'Pensalo así' -->

# Cada comparación es una pregunta

**Python responde True o False:**

```python
edad = 18

edad >= 18  # ¿Edad >= 18? → True
edad == 16  # ¿Edad == 16? → False
edad < 21   # ¿Edad < 21? → True
```

**Las respuestas son booleanas**

---

<!-- _header: 'Ejemplo práctico' -->

# Verificando condiciones

```python
edad = 18

es_mayor = edad >= 18
print(f"¿Es mayor de edad? {es_mayor}")
# True

precio = 100
tiene_descuento = precio > 50
print(f"¿Tiene descuento? {tiene_descuento}")
# True
```

---

<!-- _header: 'Importante' -->

# Comparación vs Asignación

**Asignación (=):**
```python
edad = 18  # Guarda 18 en edad
```

**Comparación (==):**
```python
es_adulto = (edad == 18)  # True o False
```

**No confundir:** `=` con `==`

---

<!-- _header: 'Con cadenas' -->

# Comparar texto

**Orden lexicográfico (diccionario):**
```python
"a" < "b"        # True
"manzana" < "pera"  # True
```

**Sensible a mayúsculas:**
```python
"Ana" == "ana"   # False
"Ana" == "Ana"   # True
```

# <!-- fit --> Operadores Lógicos
## Combinar múltiples condiciones

---

<!-- _header: '¿Para qué?' -->

# Verificar múltiples cosas

**Ejemplo de la vida real:**
* "¿Puedo conducir?"
* Necesito: tener 18 años **Y** tener licencia
* Ambas condiciones deben cumplirse

**Operadores lógicos:**
* Combinan varias condiciones
* Una respuesta final: True o False

---

<!-- _header: 'Los 3 operadores' -->

# and, or, not

**and (Y):**
* Ambas condiciones deben ser True

**or (O):**
* Al menos una debe ser True

**not (NO):**
* Invierte el valor

---

<!-- _header: 'Operador and' -->

# Y lógico (and)

**Ambas deben ser True:**
```python
True and True    # True
True and False   # False
False and True   # False
False and False  # False
```

**Ejemplo:**
```python
edad = 20
tiene_licencia = True

puede_conducir = (edad >= 18) and tiene_licencia
# True (ambas son True)
```

---

<!-- _header: 'Operador or' -->

# O lógico (or)

**Al menos una debe ser True:**
```python
True or True     # True
True or False    # True
False or True    # True
False or False   # False
```

**Ejemplo:**
```python
es_fin_semana = True
es_feriado = False

puede_descansar = es_fin_semana or es_feriado
# True (una es True)
```

---

<!-- _header: 'Operador not' -->

# Negación (not)

**Invierte el valor:**
```python
not True    # False
not False   # True
```

**Ejemplo:**
```python
esta_lloviendo = False
puede_salir = not esta_lloviendo
# True (invierte False)
```

---

|:---|:---|:--------|

**True si al menos uno es True**

# Orden de evaluación

**Prioridad:**
1. `not`
2. `and`
3. `or`

**Ejemplo:**
```python
True or False and False
# Evalúa: True or (False and False)
# Resultado: True
```
