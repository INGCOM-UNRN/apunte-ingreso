<!-- _header: '¿Qué es una variable?' -->

# Caja con etiqueta

**Analogía:**
* Variable = caja con etiqueta
* Guarda información
* Podés cambiar el contenido
* La etiqueta identifica la caja

**En programación:**
* Nombre que guarda un valor
* Espacio en memoria
* Valor puede cambiar

---

<!-- _header: 'Crear variables' -->

# Sintaxis simple

**En Python:**
```python
nombre = valor
```

**Ejemplos:**
```python
edad = 18
nombre = "Ana"
altura = 1.65
es_estudiante = True
```

**El símbolo `=` asigna un valor**

---

<!-- _header: 'Ejemplo interactivo' -->

# Crear y mostrar

```python
# Creamos variables
edad = 18
nombre = "Ana"
altura = 1.65
es_estudiante = True

# Mostramos los valores
print(f"Nombre: {nombre}")
print(f"Edad: {edad}")
print(f"Altura: {altura}m")
print(f"¿Es estudiante?: {es_estudiante}")
```

---

<!-- _header: 'Nomenclatura' -->

# Nombres descriptivos

**Buenos nombres (snake_case):**
* `edad_usuario`
* `precio_total`
* `cantidad_productos`

**Malos nombres:**
* `x`, `a`, `dato` (poco descriptivos)
* `PrecioTotal` (no es snake_case)
* `2edad` (comienza con número)

---

<!-- _header: 'Reglas' -->

# Reglas para nombres

**Deben:**
1. Comenzar con letra o `_`
2. Contener letras, números y `_`
3. No tener espacios
4. No ser palabras reservadas

**Sensibles a mayúsculas:**
* `edad` ≠ `Edad` ≠ `EDAD`

---

<!-- _header: 'Ejemplos' -->

# Válidos e inválidos

**✅ Válido:**
```python
nombre = "Carlos"
edad_2023 = 20
_valor_privado = 100
```

**❌ Inválido:**
```python
2nombre = "Error"      # Empieza con número
mi-variable = 5        # Tiene guión
for = 10               # Palabra reservada
```

---

<!-- _header: 'Reasignación' -->

# Cambiar valores

**Podés cambiar el valor:**
```python
contador = 0
print(contador)  # 0

contador = 5
print(contador)  # 5

contador = contador + 1
print(contador)  # 6
```

**Las variables son cajas, el contenido cambia**

---

<!-- _header: 'Reasignación' -->

# Experimento interactivo

```python
contador = 0
print(f"Inicial: {contador}")

contador = 5
print(f"Después de 5: {contador}")

contador = contador + 1
print(f"Incremento: {contador}")

contador = contador * 2
print(f"Duplicado: {contador}")
```

---

<!-- _header: 'Inicialización' -->

# Siempre inicializar

**❌ Error común:**
```python
print(resultado)
# NameError: name 'resultado' is not defined
```

**✅ Correcto:**
```python
resultado = 0
print(resultado)  # 0
```

**Regla: Variables antes de usarlas**

<!-- _header: '¿Por qué tipos?' -->

# Diferentes información

**En el mundo real:**
* Números para contar
* Palabras para hablar
* Sí/No para decidir

**En Python:**
* No es lo mismo `5 + 3`
* Que `"Hola" + "Mundo"`
* Python necesita saber el tipo

---

<!-- _header: 'Tipos básicos' -->

# Los 4 tipos fundamentales

**1. int (entero):**
* Números sin decimales
* Ejemplo: `18`, `-5`, `1000`

**2. float (decimal):**
* Números con decimales
* Ejemplo: `3.14`, `1.65`, `-0.5`

**3. str (cadena):**
* Texto entre comillas
* Ejemplo: `"Ana"`, `'Hola'`

**4. bool (booleano):**
* Verdadero o Falso
* Ejemplo: `True`, `False`

---

<!-- _header: 'int - Enteros' -->

# Números enteros

**Ejemplos de la vida real:**
* Tu edad: 18 años
* Días de la semana: 7
* Temperatura: -5°C
* Población: 1.000.000

**En Python:**
```python
edad = 18
temperatura = -5
año = 2023
poblacion = 1000000
```

---

<!-- _header: 'float - Decimales' -->

# Números con decimales

**Ejemplos de la vida real:**
* Altura: 1.65 metros
* Precio: 19.99 pesos
* Pi: 3.14159
* Temperatura: 36.5°C

**En Python:**
```python
altura = 1.65
precio = 19.99
pi = 3.14159
temperatura = 36.5
```

---

<!-- _header: 'str - Cadenas' -->

# Texto (strings)

**Ejemplos de la vida real:**
* Tu nombre: "Ana"
* Un mensaje: "Hola Mundo"
* Una dirección: "Calle 123"

**En Python:**
```python
nombre = "Ana"
mensaje = "Hola Mundo"
direccion = "Calle 123"
```

**Siempre entre comillas**

<!-- _header: 'bool - Booleanos' -->

# Verdadero o Falso

**Solo dos valores:**
* `True` (verdadero)
* `False` (falso)

**Ejemplos:**
```python
es_estudiante = True
tiene_descuento = False
mayor_de_edad = True
```

**Para decisiones**

---

<!-- _header: 'Verificar tipo' -->

# Función type()

**Para saber el tipo:**
```python
edad = 18
print(type(edad))  # <class 'int'>

altura = 1.65
print(type(altura))  # <class 'float'>

nombre = "Ana"
print(type(nombre))  # <class 'str'>

activo = True
print(type(activo))  # <class 'bool'>
```
