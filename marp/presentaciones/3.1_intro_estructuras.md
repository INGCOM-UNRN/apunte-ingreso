# El problema de datos sueltos

**Hasta ahora:**
* Un número: `edad = 18`
* Un texto: `nombre = "Ana"`
* Una cosa a la vez

**En la vida real:**
* Cientos o miles de datos
* Relacionados entre sí
* Necesitan organizarse

---

<!-- _header: 'El problema' -->

# Sin estructuras de datos

**Imaginate 100 estudiantes:**
```python
estudiante1 = "Ana"
estudiante2 = "Bruno"
estudiante3 = "Carlos"
# ... 97 más ...
estudiante100 = "Zoe"
```

**Problemas:**
* 100 variables diferentes
* Imposible de manejar
* No se pueden recorrer fácilmente

---

<!-- _header: 'La solución' -->

# Con estructuras de datos

**Una lista:**
```python
estudiantes = [
    "Ana", "Bruno", "Carlos", 
    # ... 97 más ...
    "Zoe"
]
```

**Ventajas:**
* 1 sola variable
* Fácil de recorrer
* Agregar/quitar elementos

---

<!-- _header: 'Analogía' -->

# La mochila organizada

**Sin estructura (datos sueltos):**
* 1 cosa en mano derecha
* 1 cosa en mano izquierda
* 1 en bolsillo
* ¿Y las otras 47? 😰

**Con estructura (mochila):**
* 50 cosas en un solo lugar
* Organizadas
* Fácil de agregar/sacar

<!-- _header: 'Dos estructuras clave' -->

# Listas y Sets

**Lista:**
* Secuencia ordenada
* Permite duplicados
* Indexable (acceso por posición)

**Set:**
* Colección desordenada
* Solo elementos únicos
* No indexable

---

<!-- _header: 'Comparación' -->

# Listas vs Sets

| Característica | Lista | Set |
|:---------------|:------|:----|
| Ordenada | ✅ | ❌ |
| Duplicados | ✅ | ❌ |
| Indexable | ✅ | ❌ |
| Mutable | ✅ | ✅ |
| Rápida búsqueda | ❌ | ✅ |

**Cada una tiene su propósito**

---

<!-- _header: '¿Cuándo usar cada una?' -->

# Listas

**Usa listas cuando:**
* El orden importa
* Necesitás acceder por índice
* Puede haber duplicados
* Lista de tareas, historial

**Ejemplos:**
* Calificaciones: `[85, 90, 78, 85]`
* Playlist: `["canción1", "canción2"]`
* Historial web

---

<!-- _header: '¿Cuándo usar cada una?' -->

# Sets

**Usa sets cuando:**
* Solo valores únicos
* El orden no importa
* Necesitás operaciones de conjuntos
* Búsqueda rápida

**Ejemplos:**
* Tags únicos: `{"python", "code"}`
* IDs de usuarios
* Eliminar duplicados

---

<!-- _header: 'Ejemplo visual' -->

# Lista vs Set

**Lista - Mantiene orden y duplicados:**
```python
notas = [85, 90, 85, 78, 90, 92]
print(notas)  # [85, 90, 85, 78, 90, 92]
```

**Set - Solo únicos, sin orden:**
```python
tags = {"python", "code", "python", "tutorial"}
print(tags)  # {"python", "code", "tutorial"}
```

---

<!-- _header: 'Operaciones básicas' -->

# Crear estructuras

**Lista:**
```python
# Vacía
lista = []
# Con elementos
numeros = [1, 2, 3, 4, 5]
mixta = [1, "texto", True, 3.14]
```

**Set:**
```python
# Vacío (usa set())
conjunto = set()
# Con elementos
letras = {"a", "b", "c"}
numeros = {1, 2, 3, 4, 5}
```

---

<!-- _header: 'Longitud' -->

# Contar elementos

**Ambos usan len():**
```python
lista = [1, 2, 3, 4, 5]
print(len(lista))  # 5

conjunto = {1, 2, 3, 4, 5}
print(len(conjunto))  # 5
```

**len() funciona con todas las estructuras**

---

<!-- _header: 'Pertenencia' -->

# Verificar si existe

**Usar in:**
```python
frutas = ["manzana", "banana", "naranja"]
print("manzana" in frutas)  # True
print("pera" in frutas)      # False

tags = {"python", "java", "javascript"}
print("python" in tags)  # True
print("ruby" in tags)    # False
```
