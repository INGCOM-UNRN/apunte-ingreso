<!-- _header: 'Comparación' -->

# Sin vs Con control de flujo

**Sin control de flujo:**
```python
# Siempre saluda igual
print("Buenos días")
print("Buenas tardes")
print("Buenas noches")
```

**Con control de flujo:**
```python
hora = 14
if hora < 12:
    print("Buenos días")
elif hora < 20:
    print("Buenas tardes")
else:
    print("Buenas noches")
```

# Los dos pilares

**1. Decisiones (Condicionales):**
* `if` - si pasa esto
* `elif` - sino si pasa esto otro
* `else` - sino

**2. Repeticiones (Lazos):**
* `while` - mientras se cumpla
* `for` - para cada elemento
* `break`, `continue` - control fino

---

<!-- _header: 'Decisiones' -->

# Condicionales: if/elif/else

**if simple:**
```python
if edad >= 18:
    print("Mayor de edad")
```

**if-else:**
```python
if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
```

---

<!-- _header: 'Decisiones' -->

# Múltiples condiciones

**if-elif-else:**
```python
if nota >= 90:
    print("Excelente")
elif nota >= 70:
    print("Aprobado")
elif nota >= 50:
    print("Suficiente")
else:
    print("Desaprobado")
```

**Solo se ejecuta UNA rama**

---

<!-- _header: 'Repeticiones' -->

# Lazos: while y for

**while - mientras:**
```python
contador = 0
while contador < 5:
    print(contador)
    contador += 1
```

**for - para cada:**
```python
for numero in range(5):
    print(numero)
```

---

<!-- _header: 'Control de lazos' -->

# break y continue

**break - salir del lazo:**
```python
while True:
    respuesta = input("Salir? (s/n): ")
    if respuesta == 's':
        break
```

**continue - siguiente iteración:**
```python
for i in range(10):
    if i % 2 == 0:
        continue  # Saltar pares
    print(i)  # Solo impares
```

---

<!-- _header: 'Patrones comunes' -->

# Validación de entrada

```python
while True:
    edad = int(input("Tu edad: "))
    if 0 < edad < 120:
        break  # Edad válida
    print("Edad inválida. Intenta de nuevo")

print(f"Edad válida: {edad}")
```

**Repite hasta que el dato sea correcto**

---

<!-- _header: 'Patrones comunes' -->

# Menú interactivo

```python
while True:
    print("1. Opción A")
    print("2. Opción B")
    print("3. Salir")
    
    opcion = input("Elige: ")
    
    if opcion == "1":
        print("Ejecutando A")
    elif opcion == "2":
        print("Ejecutando B")
    elif opcion == "3":
        break
```

---

<!-- _header: 'Patrones comunes' -->

# Acumulador

```python
# Sumar números del 1 al 100
suma = 0
for i in range(1, 101):
    suma += i

print(f"Suma: {suma}")  # 5050
```

**Patrón:** Inicializar + acumular en lazo

---

<!-- _header: 'Patrones comunes' -->

# Contador

```python
# Contar números pares
texto = "123456789"
pares = 0

for caracter in texto:
    numero = int(caracter)
    if numero % 2 == 0:
        pares += 1

print(f"Pares: {pares}")  # 4
```
