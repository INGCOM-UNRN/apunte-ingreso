# El guardia del boliche

**Situación:**
* Llega alguien al boliche
* Guardia revisa la edad
* ¿Mayor de 18? → Pasa
* ¿Menor de 18? → No pasa

**En código:**
```python
if edad >= 18:
    print("¡Bienvenido! Pasá")
```

<!--
NOTAS DEL ORADOR:
- Analogía simple y efectiva.
- Condición: `edad >= 18`.
- Acción si verdadero: `print`.
- Acción si falso: Nada (por ahora).
-->

---

<!-- _header: 'if simple' -->

# Estructura básica: if

**Sintaxis:**
```python
if condicion:
    # Código si es verdadero
    instruccion1
    instruccion2
```

**Ejemplo:**
```python
edad = 18

if edad >= 18:
    print("Sos mayor de edad")
    print("Podés votar")
```

<!--
NOTAS DEL ORADOR:
- Énfasis en la sintaxis.
- Palabra clave `if`.
- Condición que evalúa a True/False.
- Dos puntos `:` al final.
-->

---

<!-- _header: 'Anatomía' -->

# Partes del if

```python
if edad >= 18:
    print("Mayor")
    print("Votar")
print("Fin")
```

**Componentes:**
1. `if` → palabra clave
2. `edad >= 18` → condición (True/False)
3. `:` → dos puntos (obligatorio)
4. Indentación → define el bloque
5. Sin indentar → fuera del if

<!--
NOTAS DEL ORADOR:
- Explicar visualmente qué está dentro y qué está fuera.
- "Fin" se imprime SIEMPRE, sin importar la edad.
-->

<!-- _header: 'Indentación' -->

# Python usa espacios

**A diferencia de otros lenguajes:**
* No usa llaves `{}`
* Usa espacios para bloques
* La indentación ES parte del código

**Regla de oro:**
* 4 espacios por nivel
* Ser consistente
* Los editores ayudan

<!--
NOTAS DEL ORADOR:
- Tab vs Espacios: La guerra santa. En Python, PEP 8 dice 4 espacios.
- Jupyter y VS Code convierten Tab a 4 espacios automáticamente.
-->

---

<!-- _header: 'Indentación' -->

# Correcto vs incorrecto

**✅ Correcto:**
```python
if edad >= 18:
    print("Mayor de edad")  # 4 espacios
    print("Podés votar")    # 4 espacios
```

**❌ Error: Sin indentación**
```python
if edad >= 18:
print("Mayor")  # IndentationError!
```

**❌ Error: Inconsistente**
```python
if edad >= 18:
  print("Esto")    # 2 espacios
    print("Malo")  # 4 espacios
```

<!--
NOTAS DEL ORADOR:
- `IndentationError`: Amigo frecuente al inicio.
-->

# Una cosa u otra

**Cuando hay 2 opciones:**
* Si se cumple → hace esto
* Si NO se cumple → hace esto otro

**Siempre ejecuta UNA de las dos**

```python
if condicion:
    # Opción A
else:
    # Opción B
```

<!--
NOTAS DEL ORADOR:
- Exclusividad mutua.
- Nunca se ejecutan ambos bloques. Nunca se ejecutan ninguno (siempre uno).
-->

<!-- _header: 'Analogía' -->

# Moneda al aire

**Tirás una moneda:**
* Cara → ganás
* Cruz → perdés

```python
moneda = "cara"

if moneda == "cara":
    print("¡Ganaste!")
else:
    print("Perdiste")
```

**Una de las dos, nunca ambas**

<!--
NOTAS DEL ORADOR:
- Simple y claro.
-->

<!-- _header: 'Ejemplo' -->

# Mayor o menor de edad

```python
edad = 16

if edad >= 18:
    print("Sos mayor de edad")
    print("Podés votar")
else:
    print("Sos menor de edad")
    print("Todavía no podés votar")
    
print("Gracias por consultar")
```

<!--
NOTAS DEL ORADOR:
- Notar que el `else` también lleva dos puntos `:`.
- Y también requiere indentación.
-->

<!-- _header: '¿Cuándo usar?' -->

# if vs if-else

**Solo if:**
```python
if soleado:
    print("¡Vamos al parque!")
# Si no es soleado, no pasa nada
```

**Con if-else:**
```python
if soleado:
    print("¡Vamos al parque!")
else:
    print("Nos quedamos en casa")
# Siempre hacemos algo
```

<!--
NOTAS DEL ORADOR:
- `if` simple: Acción opcional.
- `if-else`: Decisión obligatoria entre alternativas.
-->

---

<!-- _header: '¿Cuándo usar if-else?' -->

# Casos comunes

**Úsalo cuando:**
* Hay exactamente 2 opciones
* Siempre querés hacer algo
* Las opciones son excluyentes

**Ejemplos:**
* Aprobar/Reprobar
* Día/Noche
* Par/Impar
* Logueado/No logueado

<!--
NOTAS DEL ORADOR:
- Lógica binaria.
-->

---

<!-- _header: 'Ejemplo práctico' -->

# Número par o impar

```python
numero = int(input("Ingrese un número: "))

if numero % 2 == 0:
    print(f"{numero} es par")
else:
    print(f"{numero} es impar")
```

**Recordá:** `%` da el resto de la división

<!--
NOTAS DEL ORADOR:
- Retomamos el operador módulo `%` que vimos en aritmética.
- Es el uso más clásico.
-->

---

<!-- _header: 'Ejemplo práctico' -->

# Validar nota

```python
nota = float(input("Tu nota: "))

if nota >= 60:
    print("¡Aprobaste!")
    print("Felicitaciones")
else:
    print("Reprobaste")
    print("Podés recuperar")
```

NOTAS DEL ORADOR:
- Ejemplo con floats y entrada de usuario.

# Descuento por edad

```python
edad = int(input("Tu edad: "))
precio_base = 100

if edad < 18:
    descuento = 0.5  # 50% descuento
else:
    descuento = 0    # Sin descuento

precio_final = precio_base * (1 - descuento)
print(f"Precio a pagar: ${precio_final}")
```

<!-- _header: 'Errores comunes' -->

# Error 1: Olvidar los dos puntos

**❌ Incorrecto:**
```python
if edad >= 18
    print("Mayor")  # SyntaxError
```

**✅ Correcto:**
```python
if edad >= 18:
    print("Mayor")
```

**Los `:` son obligatorios**

<!--
NOTAS DEL ORADOR:
- Es el error de sintaxis #1.
-->

---

<!-- _header: 'Errores comunes' -->

# Error 2: Usar = en vez de ==

**❌ Incorrecto:**
```python
if edad = 18:  # SyntaxError
    print("Tiene 18")
```

**✅ Correcto:**
```python
if edad == 18:  # Comparación
    print("Tiene 18")
```

**`=` asigna, `==` compara**

<!--
NOTAS DEL ORADOR:
- Error #2. Muy difícil de ver al principio.
-->

---

<!-- _header: 'Errores comunes' -->

# Error 3: Indentación incorrecta

**❌ Problema:**
```python
if edad >= 18:
    print("Mayor")
print("Votar")  # Se ejecuta siempre!
```

**✅ Correcto:**
```python
if edad >= 18:
    print("Mayor")
    print("Votar")  # Ambos indentados
```

<!--
NOTAS DEL ORADOR:
- Error lógico (semántico). El programa corre pero hace algo distinto a lo esperado.
-->

# Para recordar

**if simple:**
* Ejecuta código si condición es True
* Sintaxis: `if condicion:`

**if-else:**
* Dos caminos posibles
* Siempre ejecuta uno u otro
* Para situaciones binarias

**Importante:**
* Dos puntos `:` obligatorios
* Indentación de 4 espacios
* `==` para comparar, `=` para asignar
