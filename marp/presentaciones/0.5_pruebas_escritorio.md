# Pruebas de Escritorio

**Definición:**
* Ejecutar el algoritmo "a mano"
* Como si fueras la computadora
* Paso a paso, con datos reales

**¿Para qué?**
* Encontrar errores ANTES de programar
* Verificar que la lógica funciona
* Entender mejor tu algoritmo

<!-- _header: 'Ejemplo 1' -->

# Promedio de 2 números

**Pseudocódigo:**
```
LEER num1
LEER num2
suma ⟸ num1 + num2
promedio ⟸ suma / 2
MOSTRAR promedio
```

**Caso de prueba:** `num1 = 8`, `num2 = 12`

---

<!-- _header: 'Ejemplo 1' -->

# Tabla de traza

| Paso | num1 | num2 | suma | prom | Salida |
|:-----|:-----|:-----|:-----|:-----|:-------|
| LEER num1 | 8 | - | - | - | - |
| LEER num2 | 8 | 12 | - | - | - |
| suma ⟸ ... | 8 | 12 | 20 | - | - |
| prom ⟸ ... | 8 | 12 | 20 | 10 | - |
| MOSTRAR | 8 | 12 | 20 | 10 | "10" |

---

<!-- _header: 'Ejemplo 1' -->

# Verificación

**¿Es correcto?**
* 20 / 2 = 10 ✅
* Promedio de 8 y 12 es 10 ✅
* **¡Funciona!**

**Otros casos a probar:**
* Números negativos
* Números decimales
* Números iguales

# Par o Impar

**Pseudocódigo:**
```
LEER numero
SI numero % 2 == 0 ENTONCES
    MOSTRAR "Es par"
SINO
    MOSTRAR "Es impar"
FIN_SI
```

**Probamos dos casos...**

<!--
El operador % (módulo) da el resto de una división.
6 % 2 = 0 (par)
7 % 2 = 1 (impar)
-->

---

<!-- _header: 'Ejemplo 2' -->

# Caso 1: numero = 6

| Paso | numero | num%2 | Condición | Salida |
|:-----|:-------|:------|:----------|:-------|
| LEER | 6 | - | - | - |
| Evaluar | 6 | 0 | 0==0 → Verdadero | - |
| SI | 6 | 0 | Entra al SI | "Es par" |

**✅ Correcto: 6 es par**

---

<!-- _header: 'Ejemplo 2' -->

# Caso 2: numero = 7

| Paso | numero | num%2 | Condición | Salida |
|:-----|:-------|:------|:----------|:-------|
| LEER | 7 | - | - | - |
| Evaluar | 7 | 1 | 1==0 → Falso | - |
| SINO | 7 | 1 | Entra al SINO | "Es impar" |

**✅ Correcto: 7 es impar**

# Suma de 1 al 5 (con lazo)

**Pseudocódigo:**
```
suma ⟸ 0
i ⟸ 1
MIENTRAS i <= 5 HACER
    suma ⟸ suma + i
    i ⟸ i + 1
FIN_MIENTRAS
MOSTRAR suma
```

**Tabla más compleja...**

<!-- _header: 'Errores comunes' -->

# Errores que detectan las pruebas

**Error 1: Lazo infinito**
* Olvidar incrementar contador
* Condición siempre verdadera

**Error 2: Off-by-one**
* Ejecutar una vez de más o de menos
* `<=` vs `<`

**Error 3: Variables no inicializadas**
* Usar variable antes de asignarle valor

# Consejos para pruebas

**Sé metódico:**
* No saltees pasos
* Actualiza todas las variables

**Usa lápiz y papel:**
* Es más fácil que hacerlo mental

**Prueba múltiples casos:**
* Un caso no es suficiente
* Especialmente para decisiones y lazos

# Pseudocódigo → Python

**Pseudocódigo:**
```
INICIO PromedioDos
    LEER num1, num2
    promedio ⟸ (num1 + num2) / 2
    MOSTRAR promedio
FIN
```

**Python:**
```python
num1 = float(input("Número 1: "))
num2 = float(input("Número 2: "))
promedio = (num1 + num2) / 2
print(f"Promedio: {promedio}")
```
